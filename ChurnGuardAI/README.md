# 🛡️ CHURNGUARD AI
**Customer Churn Prediction & Retention Intelligence System** — MainCrafts 2-Day Skill Certification Program (Artificial Intelligence & Machine Learning)

A complete end-to-end machine-learning workflow:
`Raw Data → Data Understanding → Cleaning → Feature Preparation → Model Training → Evaluation → Prediction → Business Insight`

> ⚠️ **Dataset note — please read.** The official IBM Telco Customer Churn CSV could not be downloaded while this project was built (no internet access).
> `dataset/customer_churn.csv` is a **schema-identical replica** (same 21 columns, 7,043 rows, same quirks such as blank `TotalCharges` for new customers), generated by `dataset/generate_synthetic_dataset.py`.
> **To use the official data:** overwrite `dataset/customer_churn.csv` with the IBM (or MainCrafts) CSV, run the notebook top to bottom, then run `python report/generate_report.py`. Every number, chart and sentence in the notebook and report is computed from the data, so nothing else needs to change.

## Predict for a new customer
```python
from churnguard_utils import load_artifacts, predict_churn
model, meta = load_artifacts("models")
predict_churn({"Contract": "Month-to-month", "tenure": 5, "MonthlyCharges": 79.5, "InternetService": "Fiber optic"}, model, meta)
# -> {'predicted_churn': 'YES', 'churn_probability': 0.9..., 'risk_level': 'HIGH', 'suggested_action': '...'}
```
Fields that are not supplied are filled with typical training-data values.

## What the notebook covers
Step 2 problem questions (Q1–Q5) · Step 3 library explanations · Steps 4–5 inspection & cleaning with justified decisions · Step 6 six visualisations, each with a data-driven conclusion · Steps 7–9 features, stratified split, one-hot pipeline · Steps 10–12 Logistic Regression vs Random Forest and metric choice · Step 13 confusion matrix · Steps 14–15 prediction function & business interpretation · **Day 2:** Challenge A (6 experiments, cross-validated selection, before/after F1), feature importance, Challenge B (HIGH/MEDIUM/LOW risk with justified thresholds), model saving, Challenge C (final results summary).

## Key findings (shipped dataset)
1. Month-to-month customers churn at 45.9% vs 3.5% on two-year contracts.
2. 51.4% of customers churn in their first 12 months vs 4.4% after four years.
3. The model relies mainly on Contract, tenure and InternetService.

## Limitations
Association, not causation · single snapshot, no time dimension · class-weighted probabilities are for ranking, not exact percentages · retention cost / customer value not in the data · **ML prediction ≠ certainty.**
